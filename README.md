მარტივი, სწრაფი და სრულად ადაპტური Landing Page, რომელიც შექმნილია სუფთა **HTML5**, **CSS3** და **Vanilla JavaScript** ტექნოლოგიებით, ყოველგვარი ზედმეტი ბიბლიოთეკებისა და ფრეიმვორკების გარეშე.

---

## 📌 პროექტის მიმოხილვა

ვებ-გვერდი შედგება 4 ძირითადი სექციისგან:

1. **Hero სექცია** — გამომხატველი მთავარი სათაური გრადიენტული ტექსტით, მოკლე აღწერა, მოქმედებისკენ მომწოდებელი (CTA) ღილაკები და ინტერაქტიული ვიზუალური ბარათი.
2. **About სექცია (ჩვენ შესახებ)** — კომპანიის/გუნდის მოკლე აღწერა, ძირითადი სტატისტიკური მაჩვენებლები და ციტატის ბლოკი.
3. **Features სექცია (უპირატესობები)** — 3 მოქნილი **Flexbox** ბარათი სერვისების ჩამონათვალით, აიქონებითა და დახვეწილი Hover ეფექტებით.
4. **Contact სექცია (კონტაქტი)** — საკონტაქტო რეკვიზიტები და მარტივი საკონტაქტო ფორმა რეალურ დროში ვალიდაციითა და გაგზავნის ანიმაციით.

## ✨ ძირითადი ფუნქციები

- 📱 **Mobile-First & რესპონსიული დიზაინი** — იდეალურად ერგება ყველა ზომის ეკრანს (სმარტფონი, ტაბლეტი, დესკტოპი).
- 🧭 **Smooth Scroll ნავიგაცია** — გლუვი გადასვლა სექციებს შორის ფიქსირებული ჰედერის სიმაღლის გათვალისწინებით.
- 🍔 **მობილური ჰამბურგერ მენიუ** — ანიმირებული მენიუ პატარა ეკრანებისთვის (ავტომატური დახურვით ბმულზე ან ეკრანის გარეთ დაკლიკებისას).
- 📍 **ScrollSpy (IntersectionObserver)** — სქროლვისას მენიუში მიმდინარე აქტიური სექციის ავტომატური გამოკვეთა.
- 🎨 **თანამედროვე UI/UX** — Dark Mode სტილისტიკა, Glassmorphism ეფექტები, მიკრო-ანიმაციები და ქართული ფონტის სრული მხარდაჭერა.
- ✍️ **ფორმის ვალიდაცია** — ველების შემოწმება (სახელი, ელ-ფოსტის RegEx, შეტყობინების მინიმალური სიგრძე) და ვიზუალური უკუკავშირი მომხმარებელს.

## 🛠️ გამოყენებული ტექნოლოგიები

- **HTML5** — სემანტიკური და სუფთა მარკირება, SEO ოპტიმიზებული სტრუქტურა.
- **CSS3 (Vanilla CSS)**:
  - Flexbox განლაგება
  - CSS ცვლადები (Design Tokens)
  - Backdrop Filter (Glassmorphism)
  - მედია მოთხოვნები (Media Queries)
- **JavaScript (Vanilla JS - ES6+)**:
  - DOM მანიპულაციები და ივენთები (Event Listeners)
  - `IntersectionObserver` API
  - ფორმის მონაცემების ვალიდაცია
- **Google Fonts** — *Noto Sans Georgian* და *Outfit* შრიფტები.

## 🚀 პროექტის გაშვების ინსტრუქცია

პროექტი არ საჭიროებს `npm`-ს, `Node.js`-ს ან რაიმე დამატებითი პაკეტების დაინსტალირებას.

### მეთოდი 1: პირდაპირი გაშვება ბრაუზერში
1. გახსენით პროექტის საქაღალდე.
2. ორჯერ დააკლიკეთ `index.html` ფაილს (ან მარჯვენა ღილაკით აირჩიეთ **Open with** > **Google Chrome** / **Microsoft Edge** / **Mozilla Firefox**).
3. პროექტი მყისიერად ჩაიტვირთება ბრაუზერში.

### მეთოდი 2: VS Code Live Server გაფართოებით (სურვილისამებრ)
1. გახსენით საქაღალდე **Visual Studio Code**-ში.
2. დააინსტალირეთ გაფართოება **Live Server**.
3. დააწკაპუნეთ მარჯვენა ღილაკით `index.html`-ზე და აირჩიეთ **Open with Live Server**.
